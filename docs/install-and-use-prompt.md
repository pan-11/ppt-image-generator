## 发给使用者前

- 仓库 `pan-11/ppt-image-generator` 当前为私有仓库。仓库所有者需要先给对方账号读取权限，或提供从最新 `main` 导出的源码 ZIP。不要发送自己的 `.env`、`app-data/`、API Key 或数据库。
- 对方需要在自己的电脑上使用具有终端和文件操作能力的 AI 编程工具执行下方提示词，例如 Codex。只有文字聊天能力的工具不能直接完成本机安装。
- 对方需要自己的中转站账号、Base URL、API Key，以及与项目适配器匹配的接口协议；图片生成会使用其账号额度。
- 默认按 Windows 编写。当前项目在 Node.js `v24.13.0`、npm `11.6.2` 下通过了测试；新安装可使用 Node.js 24 LTS 的兼容版本。安装来源：[Node.js 官方下载](https://nodejs.org/en/download)、[Git for Windows 官方安装页](https://git-scm.com/install/windows)。
